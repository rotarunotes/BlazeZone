**Fonte Originale:** `raw/server 1.pdf`
**Tipo:** Presentazione didattica (13 slide)

## Takeaway Chiave
- **Topologia a Stella Estesa:** Pro (fault-tolerance, flessibilità, espandibilità) vs Contro (cablaggio maggiore, vulnerabilità centro stella).
- **Cablaggio Strutturato:** CD → BD → FD, con cablaggio Verticale (VCC) e Orizzontale (HCC).
- **Collocazione Server:** Standalone (piccole filiali, supporto RAID) → Data Center interno (CED, controllo diretto) → Server Farm esterne (sottosuolo, ridondanza alimentazione/connettività).
- **Data Center Interni vs Esterni:** Conferma e dettaglio del confronto Make/Buy già presente in [[SERVER_Appunti]].
- **Server Farm - Servizi:** Hosting, Colocation/Housing (server di proprietà dell'azienda ospitato nella farm), Server Dedicati, Server Virtuali.
- **[[Virtualizzazione]]:** Riduzione costi, consumi energetici, allocazione dinamica risorse, provisioning rapido.
