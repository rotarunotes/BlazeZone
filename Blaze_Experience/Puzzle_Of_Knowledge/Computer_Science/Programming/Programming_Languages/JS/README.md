# JS

**JavaScript** è il linguaggio di programmazione che anima il web. Se l'HTML è lo scheletro e il CSS è l'estetica, JavaScript rappresenta il **comportamento**: permette di rendere le pagine interattive, gestire dati in tempo reale e trasformare semplici documenti statici in vere e proprie applicazioni software.

Nato per piccoli script nel browser, oggi è un linguaggio **multi-paradigma** (imperativo, funzionale, orientato agli oggetti) e **cross-platform**, capace di girare su server (Node.js), dispositivi mobile e persino sistemi embedded.

---
# Caratteristiche Principali

- **Interpretato e JIT (Just-In-Time)**: Il codice viene eseguito dal motore del browser (come V8 di Chrome) senza una compilazione preventiva da parte dello sviluppatore.
- **Single-threaded**: Esegue un'operazione alla volta, ma gestisce compiti complessi grazie all'**Event Loop** e all'asincronia.
- **Tipizzazione Debole e Dinamica**: Non è necessario dichiarare il tipo di una variabile; JavaScript lo capisce dal valore assegnato e può cambiarlo a runtime.

---
# Inserire JavaScript nel Progetto

Come per il CSS, esistono diversi modi per integrare il codice:
1. **Esterno (Best Practice)**: Il codice risiede in file `.js` separati, collegati solitamente alla fine del `<body>` per non bloccare il caricamento della pagina.
    `<script src="script.js"></script>`
2. **Interno**: Tramite il tag `<script>` inserito direttamente nell'HTML.
3. **Attributi Evento**: Inserendo codice negli attributi come `onclick` (pratica sconsigliata per applicazioni moderne).
