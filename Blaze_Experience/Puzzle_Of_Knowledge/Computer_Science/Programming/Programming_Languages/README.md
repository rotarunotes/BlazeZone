# Programming_Languages
Un **linguaggio di programmazione** è un insieme di regole e istruzione che usiamo per dire a un computer esattamente cosa fare.

Ogni **linguaggio di programmazione** segue le sue regole dette **sintassi** e **semantica**

- **Sintassi:** è la grammatica del linguaggio, definisce come scrivere correttamente la struttura del programma,  ogni istruzione deve essere ben definita e non ci devono essere ambiguità, ovvero comando non può avere significati diversi
- **Semantica:** è il significato che rappresentano una serie di istruzioni con una sintassi corretta, se la semantica è sbagliata è come dire una frase grammaticalmente corretta ma che non ha senso
