# Web_Architectures

Le **architetture web** sono l'insieme di componenti software, server e protocolli che cooperano per rendere funzionanti i siti e le applicazioni che utilizziamo ogni giorno online.
Immaginale come la planimetria strutturale che definisce come i dati vengono scambiati, elaborati e mostrati sullo schermo del tuo dispositivo.
