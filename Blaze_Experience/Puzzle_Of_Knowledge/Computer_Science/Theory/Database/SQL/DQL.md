# Distinct
**Descrizione:**
È usata per **eliminare i duplicati** dal set di risultati di una query, garantendo che ogni riga o combinazione di valori restituita sia **unica**.

**Sede**

| citta  |
| ------ |
| Roma   |
| Milano |
| Roma   |
| Milano |
| Roma   |

**Query:**

``` SQL
SELECT DISTINCT citta FROM Sede;
```

**Risultato:**

| citta  |
| ------ |
| Roma   |
| Milano |
