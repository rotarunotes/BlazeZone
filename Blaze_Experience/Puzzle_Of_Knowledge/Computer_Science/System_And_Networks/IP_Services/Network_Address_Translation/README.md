# Network_Address_Translation

Il *Network Address Translation* (NAT) è un meccanismo che permette a più dispositivi di una rete locale di condividere un **unico** indirizzo IP pubblico per accedere a Internet.
Agisce come un "direttore del traffico", traducendo gli indirizzi privati in pubblici e viceversa, garantendo comunicazione e sicurezza.
