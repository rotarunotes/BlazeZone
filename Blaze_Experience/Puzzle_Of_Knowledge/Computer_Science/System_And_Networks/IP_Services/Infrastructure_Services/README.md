# Infrastructure_Services

I **servizi di infrastruttura** sono il motore invisibile di una rete informatica. 
Senza di essi, i dispositivi non potrebbero comunicare né localizzarsi a vicenda. 
Il loro compito è automatizzare la configurazione, tradurre gli indirizzi complessi e monitorare costantemente lo stato di salute dell'intera architettura di rete.
