# Inter-VLAN_Routing

L'**Inter-VLAN Routing** è il meccanismo che consente il transito di pacchetti dati tra diverse **VLAN**. Poiché ogni VLAN agisce come una sottorete separata, è necessario un dispositivo di **Livello 3** per instradare il traffico e permettere il dialogo tra i dispositivi di diverse VLAN.
