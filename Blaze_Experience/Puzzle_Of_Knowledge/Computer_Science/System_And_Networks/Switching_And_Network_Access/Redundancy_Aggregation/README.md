# Redundancy_Aggregation

Sono strategie fondamentali per garantire l’**affidabilità** e l’**efficienza** di una rete.

- **Ridondanza**: Assicura la continuità del servizio creando percorsi alternativi in caso di guasti.
- **Combina**: Più collegamenti fisici per aumentare la larghezza di banda totale disponibile tra i dispositivi
