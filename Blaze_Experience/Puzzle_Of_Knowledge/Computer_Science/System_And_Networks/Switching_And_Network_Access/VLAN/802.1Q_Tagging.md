# VALN Tagging

IEEE 802.1Q è lo standard che permette di trasportare traffico di **più VLAN sul collegamento in  trunk**.
Per farlo, inserisce un **tag di 4 byte** all'interno dell'header Ethernet di ogni frame (livello 2), in modo che gli switch sappiano a quale VLAN appartiene.

___
# Tag

Il tag si divide in due campi da 2 byte ciascuno:

```
+-----------+-----------+
|   TPID    |    TCI    |
| (2 byte)  | (2 byte)  |
+-----------+-----------+
```

## TPID
Il *Tag Protocol Identifier*,  Indica che il frame ha un tag 802.1Q

## TCI
Il *Tag Control Information*, contiene le informazioni effettive

```
┌──────────────────────────────────────────┐
| PCP (3 bit) | DEI (1 bit) | VID (12 bit) |
└──────────────────────────────────────────┘
```

| Flag    | Bit | Acronimo                 | Descrizione                                               |
| ------- | --- | ------------------------ | --------------------------------------------------------- |
| **PCP** | 3   | *Priority Code Point:*   | Identifica la priorità del frame QoS, 0 minimo 7 massimo  |
| **DEI** | 1   | *Drop Eligible Indicato* | Se 1. il frame può essere scartato in caso di congestione |
| **VID** | 12  | *VLAN ID*                | Identifica la VLAN                                        |

# Come funziona il Tagging

```
  PC-A                Switch A               Switch B               PC-B
(VLAN 10)          (trunk port)           (trunk port)           (VLAN 10)

    │   frame no tag  │                         │    frame no tag    │
    │────────────────►│  aggiunge tag 802.1Q    │                    │
    │                 │  VID = 10               │                    │
    │                 │────────────────────────►│   rimuove il tag   │
    │                 │    frame taggato        │───────────────────►│
    │                 │    [VLAN 10]            │                    │
```

- La porta che **riceve** il frame da un end-device (access port) → **aggiunge** il tag
- Il tag viaggia solo sui **trunk link** tra switch
- La porta che **consegna** il frame all'end-device (access port) → **rimuove** il tag
- Gli end-device normali **non vedono mai** il tag
