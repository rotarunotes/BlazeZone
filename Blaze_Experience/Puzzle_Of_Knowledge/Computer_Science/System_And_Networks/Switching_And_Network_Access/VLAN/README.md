# VLAN

Una **VLAN** *Virtual Local Area Network* è un approccio che permette di suddividere logicamente una singola rete fisica in più reti isolate.
Consente di raggruppare i dispositivi non in base alla loro posizione geografica, ma secondo criteri **funzionali**, migliorando drasticamente la **sicurezza** e l'**efficienza** del traffico dati.
