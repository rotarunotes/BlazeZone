# Planning_Addressing

Il **Planning and Addressing** è l'architettura invisibile che organizza una rete informatica.
Consiste nel suddividere lo spazio logico in segmenti ordinati, assegnando a ogni nodo un'identità univoca (Indirizzo IP).
Senza una pianificazione rigorosa (Tabelle di routing), i dati non troverebbero la strada, causando collisioni e inefficienze strutturali.
