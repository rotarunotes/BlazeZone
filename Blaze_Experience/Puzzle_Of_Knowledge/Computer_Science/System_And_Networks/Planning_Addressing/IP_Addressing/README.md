# IP_Addressing
L'**IP Addressing** è il sistema fondamentale che assegna un'identità univoca a ogni dispositivo connesso a una rete informatica.
Funziona come un **indirizzo postale digitale**, permettendo ai dati di essere instradati correttamente dal mittente al destinatario attraverso l'immensa infrastruttura di Internet.
