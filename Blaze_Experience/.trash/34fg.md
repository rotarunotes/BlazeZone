
| **Categoria**                                 | **Operazioni/Azioni**       | **Esempi / Descrizione**                                                                 |
| --------------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------- |
| **Carries out operations in 3 steps**         | 1. Maasurement              | Sensors measure changing physical values: weight, temperature, etc.                      |
|                                               | 2. Evaluation               | Measured data is compared with desired values in the control program.                    |
|                                               | 3. Control                  | If necessary, the controller makes adjustments to bring values into line with standards. |
| **Carries out some tasks better than humans** | Complex tasks               | E.g. making decisions based on complicated multiple factors.                             |
|                                               | Rapid decision-making tasks | E.g. guidance systems on high-speed aircraft.                                            |
|                                               | Very repetitive tasks       | E.g. monotonous work in which humans could easily lose their concentration.              |
|                                               | Dangerous tasks             | E.g. in environments where humans could be injured or killed.                            |

| **Componenti (Replicating parts of the human body)** |
| ---------------------------------------------------- |
| Moveable structure (= skeleton)                      |
| Electric, hydraulic or pneumatic systems (= muscles) |
| Power source (= heart)                               |
| System of sensors (= eyes, ears, etc.)               |
| Controller (= brain)                                 |
