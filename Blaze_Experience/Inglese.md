|     | **Tempo Verbale**         | **Struttura (Affermativa)**               | **Uso Principale**                                | **Esempio**                                |
| --- | ------------------------- | ----------------------------------------- | ------------------------------------------------- | ------------------------------------------ |
| A   | **Present Simple**        | Soggetto + Verbo (base/3ª pers. -s)       | Routine e fatti permanenti                        | I **work** every day.                      |
| B   | **Present Continuous**    | Soggetto + am/is/are + Verbo-ing          | Azioni in corso o programmi futuri                | I **am working** now.                      |
| C   | **Present Perfect**       | Soggetto + have/has + Participio Passato  | Azioni passate con effetto nel presente           | I **have worked** here for years.          |
| D   | **Present Perfect Cont.** | Soggetto + have/has been + Verbo-ing      | Durata di un'azione iniziata nel passato          | I **have been working** all day.           |
| A   | **Past Simple**           | Soggetto + Verbo-ed (o irregolare)        | Azioni finite in un tempo concluso                | I **worked** yesterday.                    |
| B   | **Past Continuous**       | Soggetto + was/were + Verbo-ing           | Azione in corso in un momento passato             | I **was working** at 10 PM.                |
| C   | **Past Perfect**          | Soggetto + had + Participio Passato       | Azione avvenuta prima di un'altra passata         | I **had worked** before you arrived.       |
| D   | **Past Perfect Cont.**    | Soggetto + had been + Verbo-ing           | Durata di un'azione fino a un certo punto passato | I **had been working** for hours.          |
|     | **Future Simple**         | Soggetto + will + Verbo (base)            | Decisioni spontanee o previsioni                  | I **will work** tomorrow.                  |
|     | **Future Continuous**     | Soggetto + will be + Verbo-ing            | Azione in svolgimento nel futuro                  | I **will be working** this evening.        |
|     | **Future Perfect**        | Soggetto + will have + Participio Passato | Azione già completata nel futuro                  | I **will have worked** 8 hours by tonight. |
|     | **Future Perfect Cont.**  | Soggetto + will have been + Verbo-ing     | Durata di un'azione proiettata nel futuro         | I **will have been working** for a month.  |

|---|---|---|---|
|Be|Was/Were|**Been**|Stato/Essere|
|Go|Went|**Gone**|Andato|
|Do|Did|**Done**|Fatto|
|Eat|Ate|**Eaten**|Mangiato|
|See|Saw|**Seen**|Visto|
|Write|Wrote|**Written**|Scritto|
